📌 프로젝트 핵심 목표

영화에 대한 개인 평가를 S~F 등급으로 분류하여 자신만의 티어리스트를 제작하고, 다른 사용자와 만료 기간 없는 공유 링크로 소통하는 5일 개발 MVP 웹 서비스.

1. 사용자 (User)
  • 주요 사용자: 소셜 로그인 회원
  • 비회원: 전체 공개 티어리스트 열람
  • 로그인 방식: 구글, 카카오 소셜 로그인
  • 닉네임: 로그인 후 직접 설정
2. 주요 기능 목적
  • S~F 등급별 영화 순위 기록
  • 타 사용자 공개 티어리스트 탐색
  • 관객 수 및 평점 기준 영화 탐색
  • 링크를 이용한 간편 공유
3. 세부 기능 및 완료 조건 Check point
구글/카카오 소셜 로그인 시뮬레이션

7. 추가 확인이 필요한 사항 (논의 필요)
  1. 관객 수 데이터: API가 관객수 데이터를 미제공할 시 인기도(Popularity) 대체 여부
  2. 영화제 출품작 직접 추가: 포스터 URL 및 평점 외에 감독/개봉연도 추가 입력 범위 지정
  3. 비공개 티어리스트: 작성자 본인 열람 가능 여부 (본 프로토타입은 본인 열람 가능)
  4. 공유 링크 수정 정책: 수정 후 접근 불가 시 새로운 버전 hash ID 발급 정책 채택
  5. 5일 개발 일정: Day 1(로그인/DB) ~ Day 5(공유/테스트) 일별 상세 작업 분배
